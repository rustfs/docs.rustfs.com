> RustFS は、メモリ使用量を抑えて効率的に動作するよう設計されています。

## テスト環境

テストに必要な最小要件は次のとおりです。

| コンポーネント | 要件 |
| - | - |
| CPU | 1 コア以上 |
| アーキテクチャ | x86、ARM |
| メモリ | 1 GB 以上 |
| ストレージ | HDD または SSD |
| Docker | 対応 |
| ネットワーク | ローカルまたはオフライン |
| OS | Windows、Linux、macOS |
| ロードバランサー | なし |
| ノード | 1 |

## 本番環境

Windows 版の RustFS は、開発とデバッグのみを目的としており、**本番デプロイには推奨しません**。本番ワークロードには [Linux](/ja/installation/linux) を推奨します。

| コンポーネント | 要件 |
| - | - |
| CPU | 2 × 12 コア以上 |
| アーキテクチャ | x86、ARM など |
| メモリ | 64 GB 以上 |
| ストレージ | SSD を推奨 |
| ネットワーク | 10 Gbps 以上 |
| OS | Linux（推奨） |
| ロードバランサー | 推奨 |
| ノード | 4 以上 |

## 専門サービス

複雑なデプロイについては、hello@rustfs.com のサポートに問い合わせてください。
