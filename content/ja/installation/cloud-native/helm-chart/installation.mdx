---
title: "Helm で RustFS をインストールする"
description: 公式の Helm チャートを使い、Kubernetes 上にスタンドアロンまたは分散構成の RustFS をインストールします。
---

このガイドでは、ソースまたは Helm リポジトリから公式の RustFS チャートを取得し、インストールして、S3 API と Console へのアクセスを確認します。

## 要件

| コンポーネント | 要件 |
|-----------|-------------|
| Helm | バージョン 3 |
| Kubernetes | `kubectl` で到達できるクラスター |
| StorageClass | RustFS データ向けの動的な PVC プロビジョニング |
| RustFS | `1.0.0-alpha.69` 以降 |

Ingress コントローラーは任意です。Ingress を有効にする場合は、`ingress.className` をクラスター内のコントローラー（`nginx` や `traefik` など）に設定します。

アクティブなクラスターと、利用できる StorageClass を確認します。

```bash
kubectl config current-context
kubectl get storageclass
helm version --short
```

## 1. チャートを取得する

Helm がチャートへアクセスする方法を選びます。どちらの方法でも `RUSTFS_CHART` を設定し、以降のインストールコマンドで使います。

<Tabs items={["リポジトリをクローン", "Helm リポジトリ"]} updateAnchor={false}>
  <Tab value="リポジトリをクローン" id="helm-chart-clone">

RustFS のソースリポジトリをクローンし、`helm/rustfs` にあるチャートを使います。

```bash
git clone https://github.com/rustfs/rustfs.git
cd rustfs
export RUSTFS_CHART=./helm/rustfs
```

  </Tab>
  <Tab value="Helm リポジトリ" id="helm-chart-repository">

[Artifact Hub](https://artifacthub.io/packages/helm/rustfs/rustfs) に掲載されている RustFS リポジトリを追加し、ローカルのリポジトリインデックスを更新します。

```bash
helm repo add rustfs https://charts.rustfs.com
helm repo update
export RUSTFS_CHART=rustfs/rustfs
```

  </Tab>
</Tabs>

## 2. スタンドアロンモードをインストールする

Pod が 1 つの開発用デプロイ向けに、values ファイルを作成します。

```yaml title="standalone-values.yaml"
mode:
  standalone:
    enabled: true
  distributed:
    enabled: false

secret:
  rustfs:
    access_key: "<your-access-key>"
    secret_key: "<your-secret-key>"

storageclass:
  name: standard
  dataStorageSize: 10Gi
  logStorageSize: 1Gi

ingress:
  enabled: false
```

`standard` をクラスター内の StorageClass に置き換えてから、インストールします。

```bash
helm upgrade --install rustfs "$RUSTFS_CHART" \
  --namespace rustfs \
  --create-namespace \
  -f standalone-values.yaml
```

## 3. 分散モードをインストールする

分散クラスターでは、Pod 数とドライブ数を明示します。データドライブの合計は `replicaCount * drivesPerNode` です。

```yaml title="distributed-values.yaml"
mode:
  standalone:
    enabled: false
  distributed:
    enabled: true

replicaCount: 4
drivesPerNode: 2

secret:
  rustfs:
    access_key: "<your-access-key>"
    secret_key: "<your-secret-key>"

storageclass:
  name: standard
  dataStorageSize: 100Gi
  logStorageSize: 1Gi

ingress:
  enabled: false
```

この例では、Pod を 4 つ、データ PVC を 8 つ作成します。すべての Pod をスケジュールでき、すべての PVC をプロビジョニングできることを確認してから、インストールします。

```bash
helm upgrade --install rustfs "$RUSTFS_CHART" \
  --namespace rustfs \
  --create-namespace \
  -f distributed-values.yaml
```

:::warning[インストール前にトポロジーを決める]

Kubernetes では、StatefulSet の `volumeClaimTemplates` を更新できません。後から `drivesPerNode` を変更するには、StatefulSet の再作成か、新規インストールが必要です。

:::

## 4. RustFS を確認してアクセスする

```bash
kubectl -n rustfs get pods,pvc,services
kubectl -n rustfs rollout status statefulset/rustfs
```

スタンドアロンモードでは、StatefulSet ではなく Deployment が作成されます。次のコマンドで確認します。

```bash
kubectl -n rustfs rollout status deployment/rustfs
```

S3 API と Console を作業用マシンへポートフォワードします。

```bash
kubectl -n rustfs port-forward svc/rustfs 9000:9000 9001:9001
```

S3 エンドポイントには `http://localhost:9000` を使い、Console は `http://localhost:9001` を開きます。

## 主要な値

| 値 | 目的 | チャートのデフォルト |
|-------|---------|---------------|
| `mode.standalone.enabled` | Pod が 1 つのスタンドアロンモードを有効にする | `false` |
| `mode.distributed.enabled` | 分散モードを有効にする | `true` |
| `replicaCount` | 分散モードの Pod 数 | `4` |
| `drivesPerNode` | Pod あたりのデータ PVC 数 | `replicaCount` から推定 |
| `storageclass.name` | PVC の StorageClass | `local-path` |
| `storageclass.dataStorageSize` | 各データ PVC のサイズ | `256Mi` |
| `storageclass.logStorageSize` | 各ログ PVC のサイズ | `256Mi` |
| `service.endpoint.port` | S3 API のポート | `9000` |
| `service.console.port` | Console のポート | `9001` |

ストレージサイズは明示的に設定することを推奨します。チャートのデフォルトは、基本的な評価だけを想定しています。
