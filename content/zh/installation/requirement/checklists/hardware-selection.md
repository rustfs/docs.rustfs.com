description: RustFS 的硬件要求。
---

> RustFS 注重效率并具有较低的内存占用。

## 测试环境

> 测试环境的最低要求：

| 组件 | 要求 |
| - | - |
| CPU | 1 核以上 |
| 架构 | x86、ARM |
| 内存 | 1 GB 以上 |
| 存储 | HDD 或 SSD |
| Docker | 支持 |
| 网络 | 本地或离线 |
| 操作系统 | Windows、Linux、macOS |
| 负载均衡 | 无 |
| 节点 | 1 |

## 生产环境

| 组件 | 要求 |
| - | - |
| CPU | 2 x 12 核以上 |
| 架构 | x86、ARM 等 |
| 内存 | 64 GB 以上 |
| 存储 | 推荐 SSD |
| 网络 | 10 Gbps 以上 |
| 操作系统 | Linux（推荐） |
| 负载均衡 | 推荐 |
| 节点 | 4+ |
