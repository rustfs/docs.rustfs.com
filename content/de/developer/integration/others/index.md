Integrationsanleitungen, die in keine der anderen Kategorien passen.

## Anleitungen

- [capo (Python)](./capo.md) — verbinden Sie das von der Community entwickelte SDK capo über synchrone oder asynchrone Clients mit RustFS.
- [rclone](./rclone.md) — synchronisieren und hängen Sie RustFS-Buckets ein und liefern Sie sie über die Kommandozeile aus.
- [tusd](./tusd.md) — nehmen Sie fortsetzbare Uploads über das tus-Protokoll in einem RustFS-Bucket entgegen.
- [JuiceFS](./juicefs.md) — hängen Sie ein POSIX-Dateisystem ein, dessen Daten in einem RustFS-Bucket liegen.
- [Nextcloud](./nextcloud.md) — verwenden Sie RustFS als externen S3-Speicher für Nextcloud-Dateien.
