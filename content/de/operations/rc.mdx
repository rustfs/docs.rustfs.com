`rc` ist der RustFS-Kommandozeilenclient für S3-Objektoperationen und die RustFS-Verwaltung. In dieser Anleitung installieren Sie `rc`, konfigurieren einen Cluster-Alias und lernen die wichtigsten Befehle zur Einsicht kennen. Die Download-Beispiele verwenden `v0.1.30`. Prüfen Sie vor der Installation die [RustFS-CLI-Releases](https://github.com/rustfs/cli/releases) auf eine neuere Version.

## Installation

### Linux

Die Standardarchive für Linux sind für eine breite Kompatibilität statisch mit musl gelinkt. Wählen Sie die Registerkarte, die zu `uname -m` passt.

<Tabs items={["AMD64", "ARM64"]} updateAnchor={false}>
	<Tab value="AMD64" id="rc-linux-amd64">

Für einen Host mit `x86_64`:

```bash
curl -fLO https://github.com/rustfs/cli/releases/download/v0.1.30/rustfs-cli-linux-amd64-v0.1.30.tar.gz
tar -xzf rustfs-cli-linux-amd64-v0.1.30.tar.gz
sudo install -m 0755 rc /usr/local/bin/rc
```

	</Tab>
	<Tab value="ARM64" id="rc-linux-arm64">

Für einen Host mit `aarch64`:

```bash
curl -fLO https://github.com/rustfs/cli/releases/download/v0.1.30/rustfs-cli-linux-arm64-v0.1.30.tar.gz
tar -xzf rustfs-cli-linux-arm64-v0.1.30.tar.gz
sudo install -m 0755 rc /usr/local/bin/rc
```

	</Tab>
</Tabs>

Wenn Ihre Umgebung ausdrücklich eine mit glibc gelinkte Binärdatei benötigt, wählen Sie auf der Release-Seite das Archiv `linux-amd64-gnu` oder `linux-arm64-gnu`.

```bash

```

### Windows

Die aktuelle Windows-Version stellt eine AMD64-Binärdatei bereit. Installieren Sie sie über den offiziellen Scoop-Bucket:

```powershell
scoop bucket add rustfs https://github.com/rustfs/scoop-bucket
scoop install rustfs/rc
```

### Installation prüfen

Öffnen Sie ein neues Terminal und prüfen Sie, ob `rc` verfügbar ist:

```bash
rc --version
rc --help
```

## Verwendung

### Alias konfigurieren

Ein Alias speichert den RustFS-Endpunkt und die Zugangsdaten, damit Sie sie nicht bei jedem Befehl wiederholen müssen. Ersetzen Sie die Zugangsdaten, bevor Sie den Befehl ausführen:

```bash
rc alias set local http://localhost:9000 <your-access-key> <your-secret-key>
rc alias list
```

`alias set` ersetzt einen vorhandenen Alias mit demselben Namen. `alias list` gibt geheime Zugriffsschlüssel nicht aus.

### Integrität des Dienstes prüfen

Prüfen Sie, ob der Dienst läuft und ob die erforderlichen Abhängigkeiten bereit sind:

```bash
rc ping local
rc ready local
```

### Cluster einsehen

Nutzen Sie den administrativen Befehl für Clusterinformationen, um Clusterstatus, Server, Laufwerke und Speicherkapazität einzusehen:

```bash
rc admin info cluster local
```

Listen Sie die Serverpools auf, wenn die Bereitstellung mehrere Speicherpools verwendet:

```bash
rc admin pool list local
```

Administrative Befehle erfordern Zugangsdaten mit den entsprechenden Berechtigungen der RustFS Admin API.

### Buckets und Objekte einsehen

Bevorzugen Sie für neue Skripte die Befehlsgruppen, die mit dem Substantiv beginnen:

```bash
rc bucket list local/
rc object list local/my-bucket
rc object stat local/my-bucket/hello.txt
```

### Lebenszyklusregeln und Speicherstufen verwalten

`rc` fasst Lebenszyklusregeln, entfernte Speicherstufen und Wiederherstellungsanforderungen unter `bucket lifecycle` zusammen:

```bash
rc bucket lifecycle rule list local/my-bucket
rc bucket lifecycle tier list local
rc bucket lifecycle restore local/my-bucket/hello.txt --days 7
```

Mit den `rule`-Befehlen fügen Sie Bucket-Lebenszyklusregeln hinzu, bearbeiten, entfernen, exportieren oder importieren sie. Mit den `tier`-Befehlen fügen Sie eine entfernte Stufe hinzu, lesen sie aus, aktualisieren ihre Zugangsdaten oder entfernen sie. Die ältere Form `rc ilm` bleibt als Kompatibilitätsalias verfügbar. Wir empfehlen für neue Skripte `rc bucket lifecycle`.

Siehe [Lebenszyklusverwaltung](/de/administration/data/lifecycle-management) für Abläufe zu Regeln und Wiederherstellung und [Gestufte Speicherung](/de/administration/data/tiered-storage) für Konfiguration und Wartung entfernter Stufen.

### Weitere Befehle anzeigen

Verwenden Sie `--help` auf jeder Befehlsebene, um die Befehle und Optionen Ihrer installierten Version anzuzeigen:

```bash
rc --help
rc alias --help
rc admin --help
rc admin info --help
rc bucket --help
rc bucket lifecycle --help
rc object --help
```

Den vollständigen Quellcode und die Befehlsreferenz finden Sie im [RustFS-CLI-Repository](https://github.com/rustfs/cli).
