`rc` est le client en ligne de commande RustFS pour les opérations sur les objets S3 et l’administration de RustFS. Ce guide installe `rc`, configure un alias de cluster et présente les principales commandes d’inspection. Les exemples de téléchargement utilisent `v0.1.30` ; consultez les [versions du CLI RustFS](https://github.com/rustfs/cli/releases) pour une version plus récente avant l’installation.

## Installation

### Linux

Les archives Linux par défaut sont liées statiquement à musl, pour une large compatibilité. Choisissez l’onglet qui correspond à `uname -m`.

<Tabs items={["AMD64", "ARM64"]} updateAnchor={false}>
	<Tab value="AMD64" id="rc-linux-amd64">

Pour un hôte `x86_64` :

```bash
curl -fLO https://github.com/rustfs/cli/releases/download/v0.1.30/rustfs-cli-linux-amd64-v0.1.30.tar.gz
tar -xzf rustfs-cli-linux-amd64-v0.1.30.tar.gz
sudo install -m 0755 rc /usr/local/bin/rc
```

	</Tab>
	<Tab value="ARM64" id="rc-linux-arm64">

Pour un hôte `aarch64` :

```bash
curl -fLO https://github.com/rustfs/cli/releases/download/v0.1.30/rustfs-cli-linux-arm64-v0.1.30.tar.gz
tar -xzf rustfs-cli-linux-arm64-v0.1.30.tar.gz
sudo install -m 0755 rc /usr/local/bin/rc
```

	</Tab>
</Tabs>

Si votre environnement exige spécifiquement un binaire lié à glibc, sélectionnez l’archive `linux-amd64-gnu` ou `linux-arm64-gnu` sur la page de la version.

Vous pouvez aussi installer le paquet avec Homebrew :

```bash
brew install rustfs/tap/rc
```

### Windows

La version Windows actuelle fournit un binaire AMD64. Installez-le avec le dépôt de paquets Scoop officiel :

```powershell
scoop bucket add rustfs https://github.com/rustfs/scoop-bucket
scoop install rustfs/rc
```

### Vérifier l’installation

Ouvrez un nouveau terminal et vérifiez que `rc` est disponible :

```bash
rc --version
rc --help
```

## Utilisation

### Configurer un alias

Un alias mémorise le point de terminaison RustFS et les identifiants, afin que vous n’ayez pas à les répéter pour chaque commande. Remplacez les identifiants avant d’exécuter les commandes :

```bash
rc alias set local http://localhost:9000 <your-access-key> <your-secret-key>
rc alias list
```

`alias set` remplace un alias existant du même nom. `alias list` n’affiche pas les clés secrètes.

### Vérifier l’état du service

Vérifiez si le service est actif et si ses dépendances requises sont prêtes :

```bash
rc ping local
rc ready local
```

### Inspecter le cluster

Utilisez la commande d’information administrative du cluster pour inspecter l’état du cluster, les serveurs, les disques et la capacité de stockage :

```bash
rc admin info cluster local
```

Listez les pools de serveurs lorsque le déploiement en utilise plusieurs :

```bash
rc admin pool list local
```

Les commandes d’administration exigent des identifiants disposant des autorisations correspondantes de l’API d’administration RustFS.

### Inspecter les compartiments et les objets

Pour les nouveaux scripts, préférez les groupes de commandes qui placent le nom en premier :

```bash
rc bucket list local/
rc object list local/my-bucket
rc object stat local/my-bucket/hello.txt
```

### Gérer les règles de cycle de vie et les niveaux de stockage

`rc` regroupe les règles de cycle de vie, les niveaux de stockage distants et les demandes de restauration sous `bucket lifecycle` :

```bash
rc bucket lifecycle rule list local/my-bucket
rc bucket lifecycle tier list local
rc bucket lifecycle restore local/my-bucket/hello.txt --days 7
```

Utilisez les commandes `rule` pour ajouter, modifier, supprimer, exporter ou importer des règles de cycle de vie de compartiment. Utilisez les commandes `tier` pour ajouter un niveau distant, l’inspecter, en mettre à jour les identifiants ou le supprimer. L’ancienne forme `rc ilm` reste disponible comme alias de compatibilité, mais nous recommandons `rc bucket lifecycle` pour les nouveaux scripts.

Consultez [Gestion du cycle de vie](/fr/administration/data/lifecycle-management) pour les flux de règles et de restauration, et [Stockage hiérarchisé](/fr/administration/data/tiered-storage) pour la configuration et la maintenance des niveaux distants.

### Découvrir d’autres commandes

Utilisez `--help` à n’importe quel niveau de commande pour voir les commandes et les options prises en charge par la version installée :

```bash
rc --help
rc alias --help
rc admin --help
rc admin info --help
rc bucket --help
rc bucket lifecycle --help
rc object --help
```

Pour les sources complètes et la référence des commandes, consultez le [dépôt du CLI RustFS](https://github.com/rustfs/cli).
