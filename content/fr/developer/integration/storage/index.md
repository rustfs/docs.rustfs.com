Use **RustFS** as the backend for storage systems and gateways built on top of object storage.

## Systems

- [lakeFS](./lakefs.md)
- [OpenDAL](./opendal.md)
- [ZeroFS](./zerofs.md)

Use a dedicated bucket and prefix per system, and scope credentials to the required bucket operations.
